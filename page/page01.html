📋 PROJECT OVERVIEW

해운대에 위치한 오뜨호텔의 공식 웹사이트로, 방문객이 객실 타입 및 위치 정보를 직관적으로 파악할 수 있도록 제작된 반응형 웹 사이트입니다. 브랜드 인지도 제고와 빠른 예약 전환을 목표로 비주얼 중심의 깔끔한 인터페이스를 구현했습니다.

⚡ KEY FEATURES
01. 반응형 UI 구축
데스크톱, 태블릿, 모바일 모든 기기 해상도에서 최적화된 레이아웃을 제공합니다.
02. 객실 모달 갤러리
별도 페이지 이동 없이 모달창에서 객실별 사진과 상세 옵션을 확인하도록 구성했습니다.
03. 외부 예약 연동
실시간 예약 및 외부 숙박 플랫폼 링크와의 직관적인 아웃바운드 구조를 구축했습니다.
